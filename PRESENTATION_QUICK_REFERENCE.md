## ❓ TOP 5 EXPECTED QUESTIONS & QUICK ANSWERS

### Q1: "How is this different from ChatGPT?"
**A:** Specialized for student mental health, maintains conversation context, has safety guardrails, never diagnoses, always suggests professional help for serious issues.

### Q2: "Is student data secure?"
**A:** Yes - bcrypt password hashing, HTTPS encryption, role-based access, MongoDB Atlas security, no third-party sharing, anonymous forum posts.

### Q3: "Can it scale to 50,000 students?"
**A:** Absolutely - tested for load, MongoDB supports 100K+ records, serverless auto-scales, API responds in <200ms even under load.

**A:** Specialized mental health prompts, tested with 100+ scenarios, never diagnoses, suggests professional help for serious issues, uses evidence-based coping strategies.
